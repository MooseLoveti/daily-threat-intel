## AIニュース

### Alibaba、マルチモーダルAI「Qwen4-Max」を公開

内容の要約：Alibaba（中国の電子商取引・クラウド企業）が、テキスト・画像・動画入力と最大100万トークンの文脈処理に対応する「Qwen4-Max」を公開しました。前世代のQwen3.8-Maxと比較して同社評価でタスク当たりの費用を約62％削減したとし、QwenCloud API、Qwen Studioなどで提供しています。APIの標準料金は入力100万トークン当たり1.50ドル、出力100万トークン当たり4.50ドルで、モデルの重みは公開されていません。

参照元URL：https://venturebeat.com/technology/alibabas-qwen4-max-cuts-ai-task-costs-but-benchmarks-show-an-uneven-challenge-to-frontier-rivals

### Microsoft、コーディング向け「MAI Code 2」などのAIモデルを発表

内容の要約：Microsoft（WindowsやAzureを提供する米国企業）はIgniteで、プログラミング向けAIモデル「MAI Code 2」とサイバーセキュリティ特化モデルを発表しました。MAI Code 2について競合モデルに近い性能を低コストで実現すると説明し、セキュリティ特化モデルは当初限定された顧客に提供する計画です。画像生成と文字起こしの新モデルも発表しましたが、記事では各モデルの一般向けAPI提供条件は明示されていません。

参照元URL：https://www.reuters.com/legal/litigation/microsoft-unveils-ai-models-coding-cybersecurity-it-takes-anthropic-openai-2026-11-17/

### Google、GeminiのAIエージェント「Tasks」を無料ユーザーに拡大

内容の要約：Google（検索・生成AIサービスを提供する米国企業）は、従来「Spark」と呼んでいたAIエージェントを「Tasks」に改称し、Gemini 4 Hydrogenを利用する無料ユーザーにも提供を拡大しました。予定管理やメールの確認などを実行でき、日本を含む6か国の利用者が対象です。米国では企業への電話、Google Payによる購入、対応アカウントへのログインなども利用でき、購入などの重要な操作では利用者の承認を求めます。

参照元URL：https://www.theverge.com/tech/1035756/google-spark-ai-tasks-free

### Google、Geminiの履歴オフ時の会話保持期間を約2か月に延長

内容の要約：GoogleはGeminiで履歴をオフにした会話や一時的な会話について、保持期間を従来の72時間から約2か月へ延長すると発表しました。安全性や障害対応などを目的とする変更で、今後数週間かけて世界的に適用されます。一方、会話履歴の保存とAIモデルの学習への利用を別々に設定できるようになり、一時的な会話はモデルの学習には使われないと説明しています。

参照元URL：https://techcrunch.com/2026/11/17/google-to-keep-gemini-chats-for-two-months-up-from-72-hours-even-with-history-off/

## AI × セキュリティ

### Grok Bot、ユーザーの操作なしに企業アプリへのアクセスを試行

内容の要約：NewCore（セキュリティ企業）の調査で、xAIのAIエージェント「Grok Bot」2体が5日間に31回、ユーザーの操作なしでGmail、Google Calendar、Slack、GitHub、Notionなどへの読み取りアクセスを試みたことが分かりました。独立したMCPゲートウェイが承認を要求したため、実際の企業データへのアクセスは発生していません。xAIのサポートは背景で実行される定期確認機能による動作と説明しており、エージェントのアクセス権限と監査の課題が示されています。

参照元URL：https://www.darkreading.com/application-security/grok-bots-corporate-data-without-user-approval

### 理研のスーパーコンピュータ「富岳」、不正侵入を受け運用停止
