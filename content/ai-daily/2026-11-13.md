# 2026-11-13 AI・セキュリティニュース

## AIニュース

### Google、Gemini 4 Hydrogenを公開しFlash系モデルを刷新

内容の要約：Google（検索・クラウド・生成AIを提供する企業）は、高速・低コスト用途向けの「Gemini 4 Hydrogen」を公開し、従来のGemini 3.8 Flashを置き換えました。Google検索では広く提供され、GeminiアプリではAI Pro・Ultra加入者が利用でき、開発者向けAPIも入力100万トークン当たり1.50ドル、出力100万トークン当たり7.50ドルで提供されます。思考レベルを4段階から選択でき、Googleは処理速度と誤情報の低減をうたっています。

参照元URL：https://arstechnica.com/google/2026/11/google-rolls-out-gemini-4-hydrogen-finally-replacing-3-8-flash/

## 脅威インテリジェンス

### 欧米当局、Gootloader・CastleRAT・StealCの犯罪インフラを摘発

内容の要約：Europol（欧州刑事警察機構）と9か国の法執行機関は、マルウェア配布基盤Gootloader、遠隔操作型マルウェアCastleRAT、情報窃取型マルウェアStealCに関連する257ドメインと235サーバーを押収しました。国際共同捜査「Operation Endgame」の一環で、犯罪インフラから約640万件の被害者データセットを特定しました。窃取された認証情報はランサムウェア攻撃などにも転用されるため、関連インフラの停止は二次被害の抑制につながります。

参照元URL：https://www.bleepingcomputer.com/news/security/police-dismantles-gootloader-castlerat-stealc-malware-infrastructure/

### 攻撃者がLinuxサーバーへの永続アクセスにGSocketを悪用

内容の要約：Microsoft（Windowsやセキュリティ製品を提供する企業）の調査によると、複数の攻撃者が正規の遠隔接続ツール「GSocket」を悪用し、侵害したLinuxサーバーへのアクセスを維持しています。中継ネットワークを通じて双方が外向き接続するため、受信側ファイアウォールによる検出を回避しやすい特徴があります。Microsoft Defender for Endpointの観測では3月から8月に関連検知が356.2%増加し、cronやsystemdを利用した永続化も確認されました。

参照元URL：https://www.bleepingcomputer.com/news/security/hackers-plant-gsocket-on-linux-servers-for-persistent-access/

## 脆弱性

### Apache HTTP ServerのHTTP/2処理に認証不要のリモートコード実行脆弱性

内容の要約：Apache Software Foundation（オープンソースソフトウェアの開発財団）は、Apache HTTP Serverのmod_http2に存在する競合状態によるリモートコード実行脆弱性「CVE-2026-119618」を修正しました。影響範囲はHTTP Server 2.4.55～2.4.70および単体のmod_h2 2.0.8～2.0.42で、HTTP/2が有効な構成では認証されていない攻撃者がWebサーバープロセスの権限でコードを実行するおそれがあります。報道時点では公開された悪用コードや実際の攻撃は確認されておらず、修正版への更新またはHTTP/2の無効化が対策となります。

参照元URL：https://www.bleepingcomputer.com/news/security/apache-http-server-patches-critical-http-2-remote-code-execution-flaw/

### WindowsのSignDrop権限昇格手法が公開、SYSTEM権限取得のおそれ

内容の要約：セキュリティ研究者Abdelhamid Naceri氏は、WindowsのCommon Log File System（CLFS、ログファイル管理用ドライバー）の認証ファイル生成処理を悪用する「SignDrop」を公開しました。特権プロセスの動作を利用してSYSTEM権限でのファイル作成を誘発し、権限昇格やセキュリティ製品の保護回避につながると報告しています。Windows 11およびWindows Serverの一部構成で検証され、記事公開時点で修正パッチはなく、実際の攻撃での悪用は確認されていません。

参照元URL：https://www.bleepingcomputer.com/news/security/new-windows-signdrop-zero-day-gives-hackers-system-privileges/

## ゼロデイ攻撃

### N-able N-centralの未修正脆弱性が実際に悪用され、少なくとも21台が侵害

内容の要約：N-able（IT運用管理ソフトウェア企業）の遠隔監視管理基盤N-centralで、新たに公開された「4EverAble2Shell」の悪用が確認されました。攻撃ではApache Axisの「CVE-2026-90436」とN-centralの権限昇格の問題を連鎖させてroot権限を取得し、少なくとも21台のサーバーで暗号資産マイナーが稼働していたと研究者が報告しています。19台は直近のHotfix 2適用環境で、N-ableはLegacy APIの無効化や機能制限を案内しています。

参照元URL：https://www.bleepingcomputer.com/news/security/new-n-able-4everable2shell-zero-day-exploited-hours-after-poc-released/

## 企業のセキュリティ動向

### Apifyが内部システムへの不正アクセスを公表、APIトークンなどを更新

内容の要約：Apify（Webデータ収集・ブラウザー自動化プラットフォームを提供する企業）は、11月9～10日に内部システムの一部へ第三者が不正アクセスしたと発表しました。同社は内部認証情報と顧客の一部APIトークンを更新し、セッションを無効化するとともにGitHubなどのOAuth連携も一部取り消しました。対象顧客には二要素認証の再設定を求めており、同社は保存されたアカウントデータへの影響を示す証拠は確認していないと説明しています。

参照元URL：https://www.bleepingcomputer.com/news/security/apify-rotates-api-tokens-prompts-2fa-resets-after-breach/
